# نظام التوصيل

تطبيق Flask لإدارة طلبات التوصيل والمصروفات وحساب صافي الربح لكل مندوب وولاية، مع تصدير التقارير إلى Excel.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح http://localhost:5000 (كلمة المرور الافتراضية `1234`).

## النشر على Railway
1. ارفع المشروع إلى مستودع على GitHub.
2. في Railway: **New Project → Deploy from GitHub repo** واختر المستودع.
3. من إعدادات الخدمة أضف **Volume** بمسار `/data` (حتى لا تضيع البيانات عند إعادة النشر).
4. في **Variables** أضف:
   | المتغير | القيمة |
   |---|---|
   | `DATA_DIR` | `/data` |
   | `APP_PASSWORD` | كلمة مرور قوية |
   | `SECRET_KEY` | نص عشوائي طويل |
5. من **Settings → Networking** اضغط **Generate Domain** للحصول على رابط الموقع.

## طريقة الاستخدام
**المدير** (يدخل بكلمة المرور `APP_PASSWORD`):
1. **المندوبين:** أضف كل مندوب باسمه ورمز PIN.
2. **الطلبيات:** سجّل الطلبيات باختيار المحافظة والولاية والعدد (يمكن إدخال عدة طلبيات دفعة واحدة).
3. تابع التوزيع: كم طلبية متاحة / مستلمة / موصّلة في كل محافظة وولاية، ومع أي مندوب.

**المندوب** (يدخل من نفس الرابط باسمه ورمز PIN):
1. يرى الطلبيات المتاحة مقسّمة حسب المحافظة والولاية مع عددها.
2. يكتب كم طلبية يستلم من كل ولاية، أو يستلم طلبية محددة.
3. من **طلبياتي** يسجّل "تم التوصيل" أو يرجع الطلبية.
