# متجر أبو ميثه

متجر إلكتروني لبيع المنتجات العمانية (البداية: السمن العماني). العميل يطلب من الموقع، يحوّل المبلغ بنكياً، ويرسل الإيصال على واتساب برسالة جاهزة.

## التشغيل محلياً
```bash
pip install -r requirements.txt
ADMIN_PASSWORD=كلمة-سر python app.py
```
ثم افتح http://localhost:5000 ولوحة التحكم على http://localhost:5000/admin

## النشر على Railway
1. في مشروعك على Railway: **New ← GitHub Repo ← masarify**، ثم من Settings ← Source اختر الفرع **omani-store**.
2. أضف **Volume** للخدمة واجعل مساره `/data` (عشان الطلبات والصور ما تضيع مع كل تحديث).
3. في **Variables** أضف:

| المتغير | القيمة |
|---|---|
| `DATA_DIR` | `/data` |
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (بدونها تبقى اللوحة مقفلة) |
| `SECRET_KEY` | نص عشوائي طويل |
| `STORE_NAME` | اختياري، افتراضياً «أبو ميثه» |

4. من Settings ← Networking اضغط **Generate Domain** (أو اربط نطاقك الخاص).

## أول ما تفتح لوحة التحكم
- **الإعدادات:** رقم واتساب المتجر، بيانات الحساب البنكي، ورسوم التوصيل لكل محافظة.
- **المنتجات:** عدّل أسعار السمن والأحجام وارفع صورة حقيقية. أضف أي منتج عماني جديد من «منتج جديد».

## حالات الطلب
بانتظار التحويل ← تم استلام التحويل ← قيد التجهيز ← خرج للتوصيل ← تم التسليم (أو ملغي، ويرجع المخزون تلقائياً).
العميل يتابع طلبه من «تتبّع طلبك» برقم الطلب (مثل AM-1001) ورقم هاتفه.
