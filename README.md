# نظام توزيع الشحنات

تطبيق Flask لتوزيع الشحنات على المندوبين حسب محافظات وولايات سلطنة عُمان.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح http://localhost:5000 (كلمة مرور الإدارة الافتراضية `1234`).

## المتغيرات (Railway → Variables)
| المتغير | الوصف |
|---|---|
| `DATA_DIR` | `/data` (مسار الـ Volume) |
| `APP_PASSWORD` | كلمة مرور الإدارة |
| `SECRET_KEY` | نص عشوائي طويل |
| `BRAND_NAME` | اسم الشركة (افتراضياً Parcel Express) |
| `BRAND_SUBTITLE` | السطر تحت الاسم |

## الأدوار
- **الإدارة:** الشحنات، رفع Excel، الحجوزات مع البحث، صفحة اليوم، المندوبين، مشرفو المحافظات.
- **مشرف المحافظة:** يدخل باختيار محافظته ورمزه، يرى حجوزات محافظته فقط ويؤكد الاستلام.
- **المندوب:** يحجز عدداً من الشحنات من الولاية التي يختارها مع موعد الاستلام، ويبلّغ المشرف عبر واتساب.

## التطبيق على الجوال
افتح الرابط من الجوال ثم: **أندرويد/Chrome:** ⋮ ← إضافة إلى الشاشة الرئيسية. **آيفون/Safari:** زر المشاركة ← إضافة إلى الشاشة الرئيسية.

## رابط باسم الشركة
1. في Railway: خدمة web ← Settings ← Networking ← **Custom Domain** واكتب مثلاً `dist.parcelexpress.om`.
2. سيعطيك Railway سجل **CNAME**؛ يضيفه قسم IT في إعدادات DNS للنطاق.
3. بعد دقائق يعمل الرابط الجديد مع شهادة HTTPS تلقائياً.
