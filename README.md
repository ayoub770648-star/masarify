# نظام توزيع الشحنات

تطبيق Flask لتوزيع الشحنات على المندوبين حسب المحافظات والولايات في سلطنة عُمان.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python app.py
```
ثم افتح http://localhost:5000 (كلمة المرور الافتراضية `1234`).

## النشر على Railway
1. ارفع المشروع إلى مستودع على GitHub.
2. في Railway: **New Project → Deploy from GitHub repo** واختر المستودع.
3. من إعدادات الخدمة أضف **Volume** بمسار `/data` (حتى لا تضيع البيانات عند إعادة النشر).
4. في **Variables** أضف:
   | المتغير | القيمة |
   |---|---|
   | `DATA_DIR` | `/data` |
   | `APP_PASSWORD` | كلمة مرور قوية |
   | `SECRET_KEY` | نص عشوائي طويل |
5. من **Settings → Networking** اضغط **Generate Domain** للحصول على رابط الموقع.

## طريقة الاستخدام
**المدير** (يدخل بكلمة المرور `APP_PASSWORD`):
1. **المندوبين:** أضف كل مندوب باسمه ورقم هاتفه ورمز PIN.
2. **الشحنات:** اختر المحافظة والولاية واكتب العدد (مثلاً ظفار ← صلالة ← 250).
3. **حجوزات المندوبين:** ترى اسم المندوب وهاتفه والعدد والولاية وموعد الاستلام.
   عند حضوره اضغط "سلّمته الشحنات". ومن نفس الصفحة تحدد: إذا بقي أقل من كم شحنة يُجبَر المندوب على أخذ الباقي.

**المندوب** (يدخل من نفس الرابط باسمه ورمز PIN):
1. يختار المحافظة والولاية، ويكتب كم شحنة يأخذ وموعد الاستلام ورقم هاتفه.
2. ينقص العدد من النظام فوراً، وإذا كان الباقي أقل من الحد يُضاف له تلقائياً.
3. من **حجوزاتي** يتابع حجوزاته ويسجّل "وصّلت الكل" بعد التوصيل.
